# Favor Bot

`bot/` теперь содержит отдельный runtime Telegram-бота для первой итерации.

Что делает бот сейчас:

- отвечает на `/start` и `/help`;
- создаёт тикеты поддержки по `/report`, принимая текст, контакт и фотографии;
- принимает deep link payloads вроде `deal_123`, `contract_slug`, `notifications`;
- ведет пользователя обратно в mini app Favor;
- служит точкой доставки сервисных уведомлений по сделкам.

Что делает приложение со стороны backend:

- создает `communication` при инициации сделки;
- отправляет через Telegram-бота уведомления о новой сделке;
- отправляет уведомления о смене статуса сделки;
- отправляет уведомления о финальных отзывах и завершении сделки.

Что не делает бот в первой итерации:

- не relay'ит переписку между сторонами;
- не хранит отдельный чат сделки;
- не заменяет прямой пользовательский Telegram-чат.

Запуск локально:

```bash
npm run bot:start
```

Запуск отдельным контейнером:

- используйте `bot/Dockerfile`;
- задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `BASE_URL`;
- задайте `TELEGRAM_SUPPORT_CHAT_ID` (ID личного чата, группы или канала поддержки, куда бот отправляет тикеты). Фото копируются средствами Telegram и не скачиваются приложением.
